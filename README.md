# WeatherToday

A Flutter weather app built with Dart and Material 3.

## Current status

This repository currently contains the initial app shell and theme preview. The
weather screen is still a placeholder; the features in `plan.md` are planned
work, not implemented functionality.

## Requirements

- Flutter SDK with Dart 3.13.4 or newer
- Android SDK and an Android device or emulator to run the Android app

## Run locally

From the project root:

```sh
flutter pub get
flutter run
```

The Android SDK and Flutter SDK paths in `android/local.properties` are
machine-specific and should not be committed. Flutter/Android tooling will
create or update this file for a local setup.
